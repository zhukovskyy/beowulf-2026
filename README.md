# Beowulf: відкритий телемедичний комплект / Open Telemedicine Kit

Сайт студентського конкурсу. Статичний HTML + CSS, без фреймворків і збирання —
публікується на GitHub Pages з гілки `main` (корінь репозиторію).

- `index.html` — українська версія
- `en/index.html` — English version
- `assets/css/styles.css` — спільні стилі за брендбуком НУВГП (світла й темна теми)
- `assets/css/fonts.css` + `assets/fonts/` — самостійно розміщені Inter і Literata
- `assets/img/` — логотипи НУВГП, favicon, схема архітектури (UA/EN), Open Graph-зображення
- `.nojekyll` — вимикає обробку Jekyll на GitHub Pages
- `LICENSE`, `LICENSE-hardware`, `LICENSE-docs`, `NOTICE` — ліцензії (див. нижче)

Розділи сторінки (однакові в обох мовах): про конкурс, як це працює,
участь, етапи, що подати, структура пропозиції, які компоненти обирати,
обладнання та бюджет, API МІС, критерії, ліцензія, важливо, контакти.

## Локальний перегляд

```sh
python -m http.server 8080
# відкрити http://localhost:8080/
```

## Заглушки, які треба замінити перед публікацією

Знайти все одразу:

```sh
grep -rn "\[.*\]" index.html en/index.html
```

| Заглушка | Де | Що вписати |
| --- | --- | --- |
| `[посилання на Google Form]` | обидві сторінки, 2 місця на кожній | URL форми заявки |
| `[телефон / Telegram]` | розділ контактів | телефон або Telegram |
| `[посилання на документацію API]` | розділ API | URL документації API МІС (після публікації) |

Після заміни видаліть блоки `.todo` з обох сторінок.

## Бренд

Оформлення відповідає брендбуку НУВГП 2025: основний колір Pantone 302 `#003A5D`,
допоміжні Cool Gray 10C `#636569` та Orange 021 `#FF5200`, шрифти Inter (основний)
і Literata (заголовки). Помаранчевий має контраст 3.25:1 на білому — використовується
лише як декор і для великого тексту, ніколи для дрібного.
